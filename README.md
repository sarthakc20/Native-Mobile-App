# Full Stack Mobile App
This is a mobile application built using the MERN (MongoDB, Express, React Native, Node.js) stack that allows users to create, post, and manage their posts. The app provides a seamless experience for writing and sharing content, leveraging a responsive UI and real-time database interactions.  

## Features  
- User authentication  
- Create, edit, and delete posts    
- Responsive and user-friendly design  

## Tech Stack  
- **Frontend:** React Native  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **State Management:** Context API
